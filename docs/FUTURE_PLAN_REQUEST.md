# Ask for more plans later

Paste the following request into a future conversation and attach your current training-pack JSON, its schema, and (optionally) a private export of recent training. Do not publish a personal export or password.

> Create additional plans for my Training Paiva app. Follow the attached `training-pack.schema.json` and existing seed conventions. Return a self-contained JSON import pack plus a short readable explanation. My available equipment is [equipment and weight increments]. My current goals are [goals]. I can train [days] for [minutes]. Current limitations are [limitations or none]. My recent actual results and recovery are [summary or attached private export].
>
> Preserve existing exercise IDs when the movement and logging semantics are identical. Add a new exercise ID for a materially different movement/variant; increment definition versions for changed definitions and plan versions for changed prescriptions. Never replace an old immutable version with different content. Include all referenced exercise and video definitions so the pack is self-contained. Include warm-ups, cooldowns, sets, rep/time ranges, rests, RIR, equipment, regressions, per-dumbbell/total/bodyweight conventions and source-checked direct YouTube links. Label verification limits. Include a schedule that accounts for recovery. Do not infer current ability from old PRs and do not include credentials or my personal measurements in the public pack.

Import through Settings -> Import plans -> Preview -> Import. The platform should retain prior definitions and session snapshots automatically. Review changed prescriptions before starting the new version.
