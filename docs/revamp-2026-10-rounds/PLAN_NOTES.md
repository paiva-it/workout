# Four fixed workouts using exercise blocks

Complete the warm-up once. For each work block, do one set of each exercise in the listed order, with the indicated pauses, then repeat that sequence for all rounds before moving to the next block. Finish the cooldown once. The PDF contains all preparation/cooldown details and clickable demonstrations.

RIR means reps in reserve: an estimate of how many more proper repetitions remain possible. The practical cue is simply 'Finish while you could still do 2-3 more good reps.' No RIR entry is required in the proposed default UI. For timed holds, stop before your position deteriorates. All weights remain manual, with no scheduled phase changes.

## A - Arms, shoulders and back

**Block 1 - Row and push-up - repeat 3 rounds**

1. Bench-supported single-arm dumbbell row: 10-15 reps per side each round.
2. Push-up: 8-15 reps each round.

Rest 60 seconds between exercises and 120 seconds between rounds. After the last round, rest 120 seconds before the next block.

**Block 2 - Shoulder press and rear delts - repeat 2 rounds**

1. Seated dumbbell shoulder press: 10-15 reps each round.
2. Seated dumbbell rear-delt fly: 10-15 reps each round.

Rest 60 seconds between exercises and 120 seconds between rounds. After the last round, rest 120 seconds before the next block.

**Block 3 - Lateral raise, triceps and curls - repeat 2 rounds**

1. Dumbbell lateral raise: 10-15 reps each round.
2. Seated French triceps extension: 10-15 reps each round.
3. Standing dumbbell curl: 10-15 reps each round.

Rest 60 seconds between exercises and 120 seconds between rounds. After the last round, continue to cooldown.

## B - Chest, shoulders and back

**Block 1 - Floor press and row - repeat 3 rounds**

1. Neutral-grip dumbbell floor press: 10-15 reps each round.
2. Bench-supported single-arm dumbbell row: 10-15 reps per side each round.

Rest 60 seconds between exercises and 120 seconds between rounds. After the last round, rest 120 seconds before the next block.

**Block 2 - Push-up, shoulder press and lateral raise - repeat 2 rounds**

1. Push-up: 8-15 reps each round.
2. Seated dumbbell shoulder press: 10-15 reps each round.
3. Dumbbell lateral raise: 12-18 reps each round.

Rest 75 seconds between exercises and 120 seconds between rounds. After the last round, continue to cooldown.

## C - Legs and glutes

**Block 1 - Squat, hinge and glute bridge - repeat 3 rounds**

1. Goblet squat: 10-15 reps each round.
2. Dumbbell Romanian deadlift: 10-15 reps each round.
3. Dumbbell glute bridge: 12-20 reps each round.

Rest 90 seconds between exercises and 150 seconds between rounds. After the last round, rest 150 seconds before the next block.

**Block 2 - Split squat and calf raise - repeat 2 rounds**

1. Dumbbell split squat: 8-12 reps per side each round.
2. Supported single-leg dumbbell calf raise: 10-20 reps per side each round.

Rest 90 seconds between exercises and 120 seconds between rounds. After the last round, continue to cooldown.

## D - Abs and core

**Block 1 - Crunch and reverse crunch - repeat 2 rounds**

1. Crunch: 12-20 reps each round.
2. Reverse crunch: 8-15 reps each round.

Rest 45 seconds between exercises and 90 seconds between rounds. After the last round, rest 90 seconds before the next block.

**Block 2 - Heel touches and side plank - repeat 2 rounds**

1. Alternating heel touches: 20-40 total reps each round.
2. Side plank: 20-40 seconds per side each round.

Rest 45 seconds between exercises and 90 seconds between rounds. After the last round, rest 90 seconds before the next block.

**Block 3 - Shoulder taps and dead bug - repeat 2 rounds**

1. Plank shoulder taps: 12-24 total reps each round.
2. Dead bug: 6-10 reps per side each round.

Rest 45 seconds between exercises and 90 seconds between rounds. After the last round, continue to cooldown.

## Schedule, effort and logging

Suggested week: Monday A, Tuesday C, Thursday B, Saturday D. Other days are easy activity or rest. Leave at least one easier day between upper-body sessions and more if needed. Resume a missed workout when recovered rather than combining sessions.

These are controlled resistance-training blocks with rest, not a speed challenge. Use more rest if needed for steady breathing and technique. Especially while returning, choose easy controllable weights and shorten a session if technique deteriorates. Old loads and personal records are not starting prescriptions. Increase weight manually by the smallest available increment when all rounds reach the top of the range with control and the intended spare reps. No automatic increase is required.

Log each exercise separately for every round. Enter kg per dumbbell for paired dumbbells. French extensions, goblet squats and loaded glute bridges use one dumbbell. Row and calf raise use one dumbbell with separate side actuals; split squats use two dumbbells with separate front-leg actuals. Heel touches and shoulder taps count once in total; dead bugs use reps per side, side planks seconds per side. A left/right pair belongs to the same round.

The exercise selection is unchanged from the previous package: floor presses, flat-seat shoulder presses, floor-based split squats and glute bridges suit the current equipment. No barbell/rack, incline bench or step platform is required. Use fixed stable supports. Keep unloaded/incline alternatives from the catalog when appropriate and record the actual movement/variant.

To give every exercise in a block the same round count, A has 3 push-up sets and 2 curl sets; D has 2 crunch sets. Those were previously 2, 3 and 3 respectively. All other work-set counts and all rep ranges are unchanged. Core is estimated at 35-50 minutes; do not add filler just to reach an hour. Rest/setup time can make any session longer.

Stop for sharp pain, dizziness, chest pain or unusual breathing difficulty; concerning symptoms warrant appropriate assessment. Follow existing medical exercise advice. The routines are general training guidance based on the requested style.
